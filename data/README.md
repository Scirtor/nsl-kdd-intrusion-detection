# Dataset files

Run `python -m nslkdd.data` from the repository root. This downloads KDDTrain+.txt and KDDTest+.txt from the immutable mirror revision in `data-manifest.json` and checks both SHA-256 hashes. Raw files are ignored by Git.

Dataset source and citation: [ISCX NSL-KDD, University of New Brunswick](https://www.unb.ca/cic/datasets/nsl.html); M. Tavallaee, E. Bagheri, W. Lu and A. A. Ghorbani, “A Detailed Analysis of the KDD CUP 99 Data Set,” CISDA, 2009. The original distributor permits redistribution with attribution to the dataset and paper. This project uses a public mirror because the distributor no longer hosts the download files.
