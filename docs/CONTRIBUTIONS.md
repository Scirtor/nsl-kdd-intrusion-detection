# Project provenance and contributions

The starting point is the NSL-KDD final project completed by team CS-2406 at Astana IT University. The original README credits:

| Contributor | Original responsibilities |
| --- | --- |
| Nurzhan Bekmurat | Data pipeline, EDA, feature engineering and report sections 1–3 |
| Shavkat Khanezar | Model training and tuning for RF, XGBoost and SVM, and the Streamlit application |

The output-stripped notebook in `legacy/` preserves the original workflow. The notebook and team work are not represented as solely authored by Nurzhan.

The October 2026 portfolio refactor was prepared with AI coding assistance. It adds modular training and input validation, train-only learned preprocessing, an explicit model selection protocol, the official test evaluation, dataset integrity checks, metrics and plots, a new local demo and automated checks. These are follow-up engineering changes, not a retroactive claim about the original division of work or an independently conducted research study.

Data files are obtained separately from a mirror and attributed to NSL-KDD and its authors. The repository does not claim ownership of the dataset or relicense the original team's work.
